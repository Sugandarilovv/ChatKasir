# Model Assets

Folder ini adalah tempat penampungan file model Deep Learning yang telah selesai dilatih.

> **PENTING:** File biner model `.keras` dan folder `SavedModel` tidak disimpan di repositori ini untuk menjaga ukuran Git tetap ringan.

## Cara Mengunduh Model untuk Inference/Deployment
1. Unduh file model melalui link Google Drive berikut:
   **https://drive.google.com/drive/folders/1J0nt-SNeBhe3omTi1v2-qxhXoVQbGAFC?usp=sharing**
2. Anda akan mendapatkan file `chatkasir_model.keras` dan `chatkasir_saved_model.zip`.
3. Letakkan (dan ekstrak zip) file tersebut ke dalam folder ini (`ai-model/assets/models/`).
