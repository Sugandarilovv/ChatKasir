# Tokenizer Assets

Folder ini adalah tempat menyimpan file tokenizers.json

## Cara Mengunduh File Tokenizer
1. Unduh file Tokenizer melalui link Google Drive berikut:
   **https://drive.google.com/file/d/1kkwRYlbHFDGXzVPMiYNx-j1Ktjv0wNHM/view?usp=sharing**
2. Anda akan mendapatkan file `tokenizer.json` dan letakkan file tersebut ke dalam folder berikut (`ai-model/assets/tokenizers/`).
