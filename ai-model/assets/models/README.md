# Model Assets

Folder ini adalah tempat penampungan file model Deep Learning yang telah selesai dilatih.

File biner model `.keras` dan folder `SavedModel` tidak disimpan di repositori ini untuk menjaga ukuran Git tetap ringan.

## Cara Mengunduh Model untuk Inference/Deployment
1. Unduh file model melalui link Google Drive berikut:
   **https://drive.google.com/drive/folders/1uCG9n7wMfF7N71P-xY3FFfJOcwUmpWwJ?usp=sharing**
2. Anda akan mendapatkan file `chatkasir_model.keras` dan folder `chatkasir_saved_model`.
3. Letakkan file dan folder tersebut ke dalam folder berikut (`ai-model/assets/models/`). Jika folder saved model berbentuk zip, silahkan di extract terlebih dahulu.
