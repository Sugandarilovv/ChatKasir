# Data Assets

Folder ini digunakan untuk menyimpan dataset biner (`.npz`)

> **PENTING:** Karena batasan ukuran file GitHub (maksimal 100MB), file dataset utama **tidak diikutsertakan** dalam repositori ini.

## Cara Mengunduh Dataset
Bagi anggota tim yang baru melakukan *clone* repositori ini, silakan ikuti langkah berikut agar skrip training dan evaluasi bisa berjalan:

1. Unduh file `dataset_chatkasir.npz` melalui link Google Drive berikut:
   **https://drive.google.com/file/d/1MiIrx-h8U4GJn3L3QJx_IxKHbD8qQ3lS/view?usp=sharing**
2. Pindahkan file yang sudah diunduh tersebut ke dalam folder ini (`ai-model/assets/data/`).
3. Pastikan nama file tidak berubah (`dataset_chatkasir.npz`).

---
*(Catatan: File ini sudah dimasukkan ke dalam `.gitignore`, sehingga perubahan atau penambahan dataset lokal di komputer Anda tidak akan ter-push ke GitHub).*
